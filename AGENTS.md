# Project instructions

This project uses Astro, TypeScript, and Tailwind CSS 4 with the Vite plugin.

- Routes live in `src/pages/`; shared components and layouts use `.astro` files.
- Keep collection data in `src/data/collections.ts`; detail routes use `getStaticPaths`.
- Preserve existing content, images, and styling when changing the implementation.
- Use Bun for dependencies and scripts. Run `bun run build` to validate types and generate the static site.
- Read the relevant official Astro documentation before changing framework-specific behavior.
